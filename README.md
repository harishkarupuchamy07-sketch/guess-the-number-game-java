# 🎯 Guess The Number Game - Java GUI

A fun and interactive number guessing game developed using Java Swing. The player must guess a randomly generated number between 1 and 100 within a limited number of attempts.

## 📌 Features

* Graphical User Interface (GUI) using Java Swing
* Random Number Generation
* Score Tracking System
* Limited Attempts for Each Round
* Instant Feedback (Too High / Too Low)
* New Round Functionality
* User-Friendly Design

## 🛠 Technologies Used

* Java
* Java Swing
* AWT Event Handling
* Random Class
* Object-Oriented Programming

## 🚀 How to Run

### Compile the Program

```bash
javac GuessTheNumberGUI.java
```

### Run the Program

```bash
java GuessTheNumberGUI
```

## 🎮 Game Rules

1. The system generates a random number between 1 and 100.
2. The player has 5 attempts to guess the number.
3. The game provides hints:

   * Too High
   * Too Low
4. Correct guesses earn points based on remaining attempts.
5. Players can start a new round at any time.
